# DOGS修復版（Devious Obligate Great Stuff）
Adds devious stuff in Bondage Club

This is a standalone repair build. It does not require the original DOGS plugin; remove the original before using this build to avoid duplicate DOGS assets.

After installing, open **DOGS修復版 Settings → Devious Padlock** and enable the feature before using the DOGS lock. It stays off by default.

### Features:
- Devious Padlock - Extremal Padlock which can't be removed by cheats
- Remote Control - Upgraded version of Universal Remote that give you more possibilities
